Системные требования

Операционная система

macOS

macOS 12.0 (Monterey) и выше.

Поддержка macOS

Cavalry 1.5.6 — последняя версия, поддерживающая macOS 10.14 и выше.

Cavalry 1.1.1 — последняя версия, поддерживающая macOS 10.13 и выше.

Windows

Windows 10 и выше.

Аппаратное обеспечение

Процессор (CPU)

macOS

Intel или ARM (Apple Silicon).

Windows

Intel или AMD.

ARM-процессоры в Windows

Для машин с ARM-процессорами под Windows будет использоваться эмулятор Prism — производительность может снизиться.

Видеокарта (GPU)

Видеокарта, совместимая с OpenGL 4.1 Core Profile.

Intel

Архитектура должна быть Gen. 12 Alder Lake или новее.

  • Драйверы Intel Graphics

NVIDIA

  • Загрузка драйверов NVIDIA

AMD

  • Поддержка AMD

Windows

Если части интерфейса отрисовываются некорректно — это признак проблемы с графикой.

Убедитесь, что драйверы видеокарты обновлены до последней версии.

Совет

На ноутбуках с Windows может быть установлено несколько видеокарт. В этом случае Cavalry попытается автоматически выбрать карту с режимом High performance. Это также можно задать вручную: Settings > System > Display > Graphics, найдите Cavalry или нажмите Browse (в разделе Custom Options for Apps), добавьте Cavalry и установите режим High performance.

Память

Минимум 512 МБ оперативной памяти.

Сеть

Для входа в Cavalry требуется подключение к интернету.

Системная диагностика

Откройте окно Help > System Diagnostics, чтобы просмотреть информацию о вашей системе. Это может пригодиться при обращении в поддержку для решения проблем.
